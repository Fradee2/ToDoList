# ToDo List App

Приложение для управления списком задач с фильтрацией и сохранением в localStorage.

## 🔗 Демо

[Посмотреть на GitHub Pages](https://fradee2.github.io/ToDoList/)

## 📋 Функционал

- Добавление новых задач
- Валидация пустого ввода
- Отметка задач как выполненных (с визуальным зачёркиванием)
- Удаление задач
- Фильтрация: Все / В работе / Завершённые
- Сохранение данных в localStorage (данные не теряются при обновлении страницы)

## 🛠️ Технологии

- HTML5
- CSS3 (Grid Layout)
- JavaScript (ES6+, Vanilla JS, DOM API)
- LocalStorage API
